# Prompt证据6：前端Vue3工程化美化 + 问答流式提速
## 1. 初始需求
我：前端界面太单调太简陋了，重做成正式项目、风格统一好看。另外问答太慢了，整整20多秒，我录视频只有8分钟等不起，要快
AI：前端重构成Vue3工程（Vite+Pinia+Router+Element Plus），新增全局主题style.css（青蓝翠绿校园配色、渐变顶栏、圆角卡片、光斑背景、Q/A气泡徽章）；/ask/接口改SSE流式输出，前端fetch流式读取实现打字机效果；Ollama模型keep_alive常驻内存避免重新加载；限制检索片段长度降低CPU推理耗时
## 2. 遇到的Bug与修复
- Bug1：美化后登录注册全部404
  我：界面变好看了，但登录点不动一直报404
  AI：vite代理带$锚定的正则（^/login/$）匹配不了带query串的POST请求，全落到SPA回退；改成字符串前缀写法（'/login/'、'/register/'等）后恢复正常
- Bug2：Element Plus默认蓝色和自定义配色打架
  我：按钮颜色一会儿蓝一会儿绿
  AI：main.js引入style.css统一覆盖Element Plus主色，按钮/输入框/弹窗全走青蓝翠绿渐变体系；历史遗留紫色色值批量替换
- Bug3：改流式后带文档的问题首字还是25秒
  我：闲聊快了，问文档内容还是要等半天
  AI：文档检索片段太长导致模型prefill慢，每个片段裁剪到300字，首字降到2.5秒，总耗时33秒降到7秒
- Bug4：流式内容显示到一半断了
  我：回答显示到一半就没了
  AI：SSE按行解析要用TextDecoder逐块解码加缓冲拼接，修正后完整显示；再加快捷键/重复提交状态锁
- 最终验证：npm run build通过，三角色全部页面风格统一并更新文档截图；问答流式打字机显示，闲聊首字2.5秒全程4秒，文档问答全程7秒
