# 2026-09-30 本地大模型部署与带溯源RAG问答 开发记录
## 用户原始需求
不想依赖云端大模型API，要本地部署开源大模型，断网也能答辩，同时实现AI回答时自动标注参考依据，不瞎编内容。
## AI协同开发过程
1.  选择Ollama作为本地大模型运行框架，避免手动配置PyTorch环境，推荐轻量中文模型qwen2:1.5b（1.1G大小，纯CPU可跑）
2.  调试过程中解决的问题：
    - Ollama命令找不到：装完软件需要重启终端加载环境变量
    - 拉模型报404：模型仓库名错误，正确标签是qwen2:1.5b，不是1.8b
    - uvicorn命令找不到：新窗口需要先激活venv虚拟环境
    - openai模块找不到：venv环境隔离，需要在激活的虚拟环境里重新pip install openai
3.  核心代码实现：
    - 新增llm.py模块，封装Ollama本地接口调用
    - 改造/ask接口：先调用RAG检索Top3相关文档片段，拼接prompt强制模型只根据文档内容回答，再调用本地大模型生成自然语言回答
    - 自动整理溯源信息：根据命中的doc_id查询对应文档名，返回给前端展示参考来源
4.  测试验证：
    - 提问"你介绍一下自己"，系统正确返回"根据现有资料暂时找不到相关信息"，验证防幻觉机制生效，没有编造无关内容
    - 针对文档内容提问，AI生成通顺回答，同时标注参考的文档名和相关度分数，完全满足"AI回答带依据溯源"的要求。
