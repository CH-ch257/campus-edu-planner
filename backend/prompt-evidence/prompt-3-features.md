# 2026-10-01 自动分类/权限管理/版本管理功能 开发记录
## 用户原始需求
按照指导老师建议，新增三个产品功能：
1.  上传文档后自动根据内容分类，不要关键词匹配，支持管理员人工修正
2.  实现两级权限：学生只能查询问答，管理员才能上传/删除文档
3.  支持文档版本管理，同名文档自动保留历史版本，学生只看最新版
## AI协同开发过程
1.  自动分类功能：
    - 给documents表新增category、category_confirmed字段
    - 在llm.py里新增classify_document函数，取文档前500字调用本地大模型，按校园场景分类为培养方案/考试通知/课件资料/行政通知/社团文件
    - 新增管理员接口：支持手动修正分类结果，修正后标记为人工校准
    - 解决的问题：数据库缺少category列导致500错误，通过ALTER TABLE手动加字段修复
2.  两级权限：
    - 给上传接口增加admin_secret参数校验，学生不带密钥无法上传，返回403权限不足
    - 学生端默认开放文档查询、搜索、问答接口，无需权限
3.  版本管理：
    - 给documents表新增version、is_latest、parent_doc_id字段
    - 上传同名文档时，自动把旧版本标记为非最新，新版本版本号+1
    - 学生端文档列表默认只返回is_latest=1的最新版本
    - 新增管理员接口：可以查看某份文档的所有历史版本
4.  测试验证：
    - 上传同名操作系统课件，系统自动检测旧版本，升级到v2
    - 上传时正确自动分类，分类错误时管理员可手动修正
    - 不带密钥调用上传接口，正确返回403权限不足
