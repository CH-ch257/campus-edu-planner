# Prompt证据3：自动分类/两级权限/版本管理功能开发
## 1. 初始需求
现在的系统太基础了，要加：1. AI自动给文档分类 2. 两级权限，只有管理员能上传 3. 文档版本管理，同名文档自动保留旧版本
AI：帮我一步步加：documents表新增category/version/is_latest/parent_doc_id字段，上传后自动调用大模型按校园场景分类，管理员密钥校验，同名上传自动标记旧版本
## 2. 遇到的Bug与修复
- Bug1：上传之后学生列表看不到新文档
  我：我刚传完文档，右边列表里根本不显示
  AI：排查发现新上传的文档is_latest字段没设成1，被学生列表过滤了，显式赋值doc.is_latest=1之后解决
- Bug2：前端跨域请求被浏览器拦截
  我：fetch调用后端接口报CORS错误
  AI：在FastAPI里加CORSMiddleware中间件，允许跨域访问
- Bug3：前端点管理员登录之后，文档下面的删除/改分类按钮不显示
  我：我都登录管理员了，怎么没有操作按钮
  AI：发现登录成功之后没重新渲染文档列表，加了loadDocs()重新渲染，按钮就出来了
- Bug4：上传同名文档的时候，版本号没自动升级
  我：我传了个同名的第二次文档，列表里还是旧版本
  AI：加了版本升级逻辑，旧文档is_latest设为0，新文档版本号+1，学生只看最新版，管理员能查所有历史版本
