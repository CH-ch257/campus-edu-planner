# Prompt证据2：本地大模型部署与流式问答
## 1. 初始需求
我：现在检索能找到了，但只会返回原文，怎么接大模型让它用大白话回答，还要标注回答来自哪个文档。另外问答太慢了，整整20多秒，我录视频只有8分钟等不起，要快
AI：本地装Ollama拉取qwen2.5:3b模型，用OpenAI兼容接口实现RAG问答链路并自动标注参考来源；设置相似度阈值0.45区分文档问答与闲聊（检索不相关时走正常对话不硬套文档）；/ask/接口改SSE流式输出，前端fetch流式读取实现打字机效果（首字2-3秒显示不用等算完）；模型keep_alive常驻内存避免重新加载，限制检索片段长度降低推理耗时
## 2. 遇到的Bug与修复
- Bug1：bash输入ollama命令找不到
  我：为什么提示ollama: command not found
  AI：把Ollama安装目录加到系统环境变量，新开窗口即可识别命令
- Bug2：模型拉取失败file does not exist
  我：ollama pull qwen2:1.5b报manifest不存在
  AI：核对正确模型名换成qwen2.5:3b，成功拉取1.9GB模型（之前写成不存在的仓库名）
- Bug3：调用大模型时前端一直转圈
  我：点提问之后页面一直没反应
  AI：llm.py加超时和异常兜底，大模型无响应也返回检索内容，页面不会卡死
- Bug4：聊天闲聊被硬套文档，答非所问
  我：我问"你好"它老答文档内容
  AI：加相似度阈值0.45，检索结果与问题明显不相关时走正常对话不引用文档
- Bug5：改流式后带文档的问题首字还是25秒
  我：闲聊快了，问文档内容还是要等半天
  AI：文档检索片段太长导致模型prefill慢，每个片段裁剪到300字，首字降到2.5秒，总耗时从33秒降到7秒
- Bug6：流式内容显示到一半断了
  我：回答显示到一半就没了
  AI：SSE按行解析需用TextDecoder逐块解码加缓冲拼接，修正后完整显示，并加asking状态锁防止重复提交
- 最终验证：闲聊首字2.5秒全程4秒，文档问答首字2.5秒全程7秒，回答带参考来源，Dart相关问题正确回答
