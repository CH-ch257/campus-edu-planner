# Prompt证据5：文档管理迁移教师 + 管理员后台 + 评语与删除
## 1. 初始需求
我：文档管理（上传/删除/改分类/历史版本/回滚）原来归管理员，现在反过来：老师管文档，高级管理员只管用户管理和公开内容总管理，老师只能删/管自己上传文档相关的公开问答。老师还要能给学生问答写评语备注；管理员用户管理不用禁用，直接删除账号
AI：文档5个接口鉴权从admin_secret密钥改为登录token+教师角色校验，documents表加teacher_id记录上传归属；新增管理员用户管理、公开内容总管理和教师评语接口；qa_records加teacher_note字段（评语与学生自己note独立），学生历史/主页/分享全端展示评语；用户管理操作改为直接删除（级联清理该用户文档与问答，admin账号保护不可删）
## 2. 遇到的Bug与修复
- Bug1：老师上传/删除文档报403
  我：老师登录了还说"仅教师可执行此操作"
  AI：前端请求还带旧的admin_secret参数，后端已改Bearer token鉴权，统一换Authorization头后解决
- Bug2：老师管不了旧文档，一直提示"只能管理自己上传的文档"
  我：以前传的文档老师现在一个都删不了，评语也写不了
  AI：查库发现历史文档teacher_id全是NULL（迁移补列没回填），把已有教学文档归属统一回填到teacher账号
- Bug3：管理员公开内容管理页空白
  我：admin登录后公开内容管理页不显示
  AI：管理员接口代理路径没配全，vite代理补上/admin/qa等规则后正常
- Bug4：删除老师账号后文档还在
  我：删了老师，他传的文档还在列表里
  AI：删除接口补级联清理，先删该用户文档和问答记录再删账号；admin自己不可删
- 最终验证：teacher可上传/删除/改分类/回滚文档并给学生问答写评语；admin只能管用户和公开内容；删除账号后列表即时消失
