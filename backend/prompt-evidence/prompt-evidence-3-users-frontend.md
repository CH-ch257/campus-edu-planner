# Prompt证据3：用户权限体系与前端工程化
## 1. 初始需求
我：系统要区分三种人：高级管理员、老师、学生，登录后进入各自界面；每次问答留记录，问答能设公开/仅链接/私有权限，公开的生成分享链接，个人主页展示公开问答；文档管理（上传/删除/改分类/版本/回滚）反过来让老师管，高级管理员只管用户管理和公开内容总管理，老师只能管自己上传文档相关的公开问答；老师要能给学生问答写评语；管理员用户管理不用禁用直接删除账号；前端界面太单调太简陋，重做成正式项目风格统一
AI：users表加role/status/token字段，预设admin/teacher固定账号，注册只开放学生；前端Vue3工程化（Vite+Pinia+Router+Element Plus）按角色渲染导航、路由守卫防越权；qa_records表存留痕+备注+三档权限+分享token；文档接口鉴权改token+教师角色校验，documents表加teacher_id归属；新增管理员用户管理/公开内容总管理、教师评语（teacher_note字段，与学生note独立）、用户直接删除（级联清理，admin保护）；全局style.css翠绿校园主题统一美化所有页面
## 2. 遇到的Bug与修复
- Bug1：旧数据库没role字段启动报错
  我：一启动就报no such column: users.role
  AI：init_db加轻量迁移，检测缺列自动ALTER TABLE补上，不丢数据
- Bug2：登出后登录页进不去一直重定向
  我：退出之后点登录页白屏转圈
  AI：localStorage残留脏登录态，守卫改token+role双校验，缺任一强制回登录页
- Bug3：学生手输网址能直接打开管理员后台
  我：直接输/admin网址居然能进管理员页面
  AI：每个角色路由加beforeEach前置守卫，越权一律重定向回自己首页
- Bug4：问答历史页空白接口报405
  我：点进问答历史一条记录都没有
  AI：vite代理漏配/qa和/me路径，补上正则代理后正常
- Bug5：分享链接打开404
  我：复制分享链接到新窗口打不开
  AI：/share/:token路由没进免登录白名单被守卫拦，公开路由单独列出后正常
- Bug6：老师上传/删除文档报403
  我：老师登录了还说"仅教师可执行此操作"
  AI：前端请求还带旧admin_secret参数，后端已改Bearer token鉴权，统一换Authorization头解决
- Bug7：老师管不了旧文档，写评语/删除都提示"只能管理自己上传的文档"
  我：以前传的文档老师一个都管不了
  AI：历史文档teacher_id全是NULL（迁移补列没回填），把已有教学文档归属统一回填到teacher账号
- Bug8：管理员公开内容管理页空白
  我：admin登录后公开内容管理页不显示
  AI：管理员接口代理路径没配全，vite代理补上/admin/qa等规则后正常
- Bug9：美化后登录注册全部404
  我：界面变好看了但登录点不动，一直报404
  AI：vite代理带$锚定的正则（^/login/$）匹配不了带query串的POST请求全落到SPA回退，改成字符串前缀写法后恢复正常
- Bug10：Element Plus默认蓝色和自定义配色打架、历史页残留紫色
  我：按钮颜色一会儿蓝一会儿绿，历史页还是旧的紫色
  AI：main.js引入style.css统一覆盖主色，所有视图紫色色值批量替换为青蓝色系
- Bug11：删除老师账号后文档还在
  我：删了老师，他传的文档还在列表里
  AI：删除接口补级联清理，先删该用户文档和问答再删账号；admin自己不可删
- 最终验证：三种账号登录进入各自界面互不越权；问答留痕/三档权限/分享/主页全通；教师可管文档写评语，学生历史/主页/分享全端可见评语；管理员删除账号即时生效；npm run build通过，全部页面风格统一并更新技术文档截图
